# ☕ Retail Store Sales Analysis using Python

## Overview

This project analyzes the sales performance of Brew Bite retail outlets located across different regions. The main objective was to understand sales trends, customer behavior, profitability, and overall store performance using Python.

The project includes data cleaning, exploratory data analysis (EDA), feature engineering, and correlation analysis to identify useful business insights that can support decision-making.

---

## Project Objective

The goal of this project is to:

- Analyze sales performance across different zones and store formats.
- Identify revenue and profit trends.
- Understand customer footfall and purchasing behavior.
- Create business KPIs through feature engineering.
- Generate insights and recommendations based on data.

---

## Dataset Information

The dataset contains monthly sales data of Brew Bite outlets from January 2023 to August 2024.

Some of the important columns in the dataset include:

- Outlet Name
- Area
- Zone
- Store Format
- Store Size
- Month
- Footfall
- Orders
- Revenue
- Profit
- Marketing Spend
- Total Cost
- Utilities
- Salaries

## Feature Engineering

To gain additional insights, the following KPIs were created:

- Revenue per Customer
- Profit per Order
- Cost per Order
- Revenue per Square Foot

These features helped evaluate customer spending, operational efficiency, and store performance.

---

## Business Questions Answered

Some of the questions explored in this project include:

- Which zone generated the highest revenue?
- Which store format earned the highest profit?
- How did monthly revenue change over time?
- Which outlets had the highest customer footfall?
- Which stores generated the highest revenue?
- Which zone had the highest revenue per customer?
- Which store format had the highest profit per order?
- Does store size have any relationship with revenue?

---

## Key Findings

- South zone generated the highest total revenue.
- Revenue showed a strong positive relationship with customer footfall and number of orders.
- Marketing spend was positively correlated with revenue.
- Revenue per customer varied across different zones.
- Revenue per square foot helped identify how efficiently store space was being utilized.
- Profit per order highlighted differences in profitability among store formats.

---

## Business Recommendations

- Study the strategies used by high-performing outlets and implement them in lower-performing locations.
- Increase customer footfall in underperforming zones through targeted marketing campaigns.
- Improve operational efficiency to reduce cost per order.
- Focus on increasing average customer spending through promotions and product bundles.
- Continue monitoring key business KPIs for better decision-making.
